# Sharmila R – Student Evidence Portfolio

## Open on your laptop
1. Unzip the folder.
2. Double-click `index.html` (Chrome or Edge recommended). Everything uses relative paths, so no server is needed.
   If a PDF does not preview inside the viewer, use "Open in new tab" or "Download".

## Publish for a shareable link (free)
- **Netlify Drop:** go to app.netlify.com/drop and drag the whole unzipped folder in. You get a link immediately.
- **GitHub Pages:** create a repository, upload all files (keep `index.html` at the top level), then Settings → Pages → Deploy from branch `main`.

## Add or edit content
- All text lives in `js/data.js`. Evidence files live in `assets/docs/` (thumbnails in `assets/thumbs/`).
- To add a certificate: copy the file to `assets/docs/`, add a thumbnail image to `assets/thumbs/`, and add an entry to the `items` list in `data.js` (copy an existing entry).
- Add GitHub / LeetCode links in the `profiles` list. Add projects in the `projects` list.
